# 高齢者見守りアプリ 試作版（第1段階）

## この段階でできること
- 縦置きタブレット向け4列×6行の固定ダッシュボード
- 文字色を黒系で統一、ウィジェットごとに淡い背景色
- 日付・時刻の自動更新
- PWAのインストール設定
- Service Workerによる基本的なオフライン表示

※予定・服薬・血圧・メッセージ・健康情報・アドバイスは画面確認用のサンプルです。まだ保存・同期されません。

## GitHub Pagesへの公開
1. GitHubで新しいPublicリポジトリ `app-010-elderly-support` を作成
2. このZIPを展開
3. 展開したフォルダの中身（index.htmlなど）をリポジトリの直下にアップロード
4. GitHubのリポジトリで Settings → Pages を開く
5. Build and deployment の Source を `Deploy from a branch` にする
6. Branchを `main`、フォルダを `/(root)` にして Save
7. 数分後に表示される公開URLを開く

## タブレットへのインストール
- Android/Chrome: 公開URLを開き、ブラウザメニューから「アプリをインストール」または「ホーム画面に追加」
- iPad/Safari: 共有ボタンから「ホーム画面に追加」
- PWAのインストール可否や表示名は端末・ブラウザによって異なります。
